# XWORT Unlimited

Deutsches Mini-Kreuzworträtsel (Allgemeinwissen) im Stil eines täglichen Rätsels, aber **ohne Wartezeit**:
mit „Neu ↻“ gibt es sofort ein neues Rätsel, so oft du willst.

- Einfach `index.html` im Browser öffnen (keine Installation, kein Server nötig).
- Jedes Rätsel hat eine Nummer (`?p=12345` in der URL) und lässt sich teilen oder erneut spielen.
- Funktionen: Timer, Prüfen, Tipp (Wort aufdecken), Lösen, Statistik (Bestzeit, Ø-Zeit, Serie), Bildschirmtastatur, Dark Mode.
- Neue Begriffe in `words.js` ergänzen: `ANTWORT|Hinweis` (Umlaute als AE/OE/UE, ß als SS).
